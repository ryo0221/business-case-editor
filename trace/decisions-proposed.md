# 判断の案

作業役が、仕様に無いことで決めたこと・答えてもらったことの案。受け入れるときに見て、仕様に取り込むか決める。

## IRR の一意性を証明できない場合の扱い

現時点の計算では符号変化が複数の場合に根の一意性を証明できないため、推測せず計算を拒否する暫定案とする。一般の複数根・一意根の判定は未実装。

## カード用の既存試験の入力

カード用モデルが残っている間、その試験は収支形式の見本ではなく試験内で作成したカード文書を使う。収支形式の見本は収支計算の試験に使用する。

## Undo 後の採番回避

セッション中の発行済み連番の最大値を保持し、文書の lastIssued との大きい方から次の ID を発行する。保存前に lastIssued を大きい方へそろえる。セッションをまたぐ ID 再利用は残る課題とする。

## セッション内の採番上限を維持する回避策

文書とセッション内で発行済みの最大値の大きい方から次のIDを発行し、保存前に文書の採番上限をそろえる。セッションをまたいだID再利用は残る課題とする。Editor Platform の履歴に関する課題は open-editor-platform #64。
